# AI-assisted development disclosure

- **What was AI-assisted:** scaffolding and drafting of the FastAPI backend,
  React frontend, test files, dataset generator, and documentation were
  drafted with an AI coding assistant (Muse) from the assignment PDF, then
  reviewed, tested, and corrected by the developer — including two real bugs
  found by running the code (invoice-number regex capturing the word
  "INVOICE", and "total" matching inside "subtotal"), which were fixed and
  re-verified before submission.
- **What is NOT AI-generated at runtime:** invoice extraction in the
  evaluated configuration is deterministic code (regex/heuristics + table
  mapping). No LLM is called unless the operator sets `LLM_API_KEY`.
- **Data:** all evaluation invoices are synthetic, generated by
  `scripts/generate_dataset.py` (fictional suppliers/customers). No real
  company documents were used.
- **Verification:** every metric in `evaluation/evaluation_report.md` comes
  from `scripts/evaluate.py` output (`evaluation/metrics.json`) and the
  pytest run, not from estimates.
